### 7.6 时间同步（0xA5 / 0x107~0x108）

以太网与 RS232 **相同线格式**：每个 UDP 包 = 一个 **11B 服务帧** `[0xA5][ID_H][ID_L][8B payload]`，与 BLOB `0xAB` 独立混传。

**默认**（`jetson_eth_bringup`）：连接时 START + 10 次 PING burst；运行期 1 Hz PING + 10 s QUERY。

```bash
ros2 launch agv_base_driver jetson_eth_bringup.launch.py   bind_ip:=192.168.10.201 mcu_ip:=192.168.10.30

ros2 topic echo /jetson_eth/time_sync --field rtt_ms
ros2 topic echo /jetson_eth/time_sync --field offset_ms
ros2 topic echo /jetson_eth/time_sync --field utc_unix_sec
```

**期望 log**：`TimeSync START`、`TimeSync PING rtt=...`、`TimeSync QUERY tick=... utc=...`

| 指标 | 期望 |
|------|------|
| `rtt_ms` | 以太网约 1~10 ms |
| `offset_ms` | PING 后稳定收敛 |
| RX 统计 `svc=` | 每 5s 有计数 |

> TimeSync **不等于** BLOB 心跳；`link_state=0` 表示心跳正常。

关闭：`time_sync_enable:=false`
